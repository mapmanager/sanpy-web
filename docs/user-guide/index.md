# User guide

SanPy Web can open a hosted SanPy Zarr collection by URL or a local collection
folder selected in a supported browser. After loading a collection, select a
recording to inspect its traces, analysis overlays, and analysis-results table.

NicePool provides linked plots for exploring the loaded analysis results. Plot
presets configure useful starting layouts while controls remain available for
changing columns, grouping, coloring, and filters.

Continue with [Opening data](opening-data.md).
