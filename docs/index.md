# SanPy Web

SanPy Web is a static browser application for exploring self-contained SanPy
Zarr collections. It displays recording signals, SanPy analysis overlays, and
tabular analysis results without requiring a server-side application.

[Open SanPy Web](https://mapmanager.github.io/sanpy-web/){ .md-button .md-button--primary }

Use the [user guide](user-guide/index.md) to open a collection, or see the
[technical documentation](technical/index.md) for development and data-contract
details.
